### E-commerce Purchasing & Customer Retention Analysis

[**shopify-purchasing-behavior-analysis**](https://github.com/Raf-Hs/shopify-purchasing-behavior-analysis)

Analyzed purchasing behavior and customer revenue concentration to identify opportunities for customer retention.

- Examined 5,061 orders across 2,008 customers.
- Found that 33.3% of customers generated 75.7% of revenue, while repeat customers generated 5.6× the revenue of non-repeat customers.
- Built an interactive dashboard with 13 visualizations and validated the project with automated tests.

**Stack:** Python, SQL, Streamlit, Plotly.
